# Rung 1: Night Shift

## Goal
Create a playable, offline-friendly browser arcade horror shooter set in 1947 South Branch Chicago adjacent to the BLACKOUT story, using original art and no runtime dependencies.

## Acceptance criteria
- Three themed scenes: Dock Gate, Freight Hall and Sealed Hold
- Six escalating waves, manual six-shot revolver reload, scoring, health, and replay
- Pointer/touch/keyboard controls and accessible target buttons
- Platform-neutral combat state suitable for a future WebXR adapter
- Unit tests and GitHub Actions PR checks
- Optional JSON narrative receipt that does not change BLACKOUT saves or make canon claims
- MIT license and GitHub Pages deploy route

## Out of scope
Quest 3 WebXR and network co-op will be separate rungs; no dependence on them for single-player.
